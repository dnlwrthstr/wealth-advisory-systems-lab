## One-liner

Refine `fund_lookthrough_skill` to enhance factsheet's top-N projection with the proxy's full constituent list, plus marker-based list-replacement semantics on the merger.

## Background

Spec-003 added `fund_lookthrough_skill` with a strict "fires only when holdings empty" predicate. Live validation on LU1681043599 (Amundi MSCI World Swap) revealed that for funds where the issuer publishes proper index composition, `fund_factsheet_skill` produces a top-N projection (e.g. 10 of 1310 MSCI World constituents). The lookthrough predicate short-circuits, so the proxy fallback never fires — users get the top-10, not the full ~1310.

Two-part fix needed:
1. Predicate refinement: fire when `len(holdings) < holdingsCount`.
2. Merger work for size-based list replacement: use a `_replace` sentinel in the patch (marker-based override) so lookthrough can replace the existing list.

## Decisions captured before spec drafting

- **Feature name**: `lookthrough-full-list` (action-oriented, scope = "complete the top-N to the full list").
- **Merger approach**: marker-based override (`_replace` sentinel). Scopes the change to lookthrough; doesn't affect equity / bond / issuer chains.
